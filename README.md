
## 🎯 How to Run

1. **Clone or download** this repository
2. **Open** `index.html` in any modern web browser
3. **Start tracking** your job applications!

No server, no installation, no dependencies required!

## 📱 Responsive Breakpoints

- **Desktop**: > 1024px - Full table view with 5-column statistics
- **Tablet**: 768px - 1024px - 3-column statistics
- **Mobile**: < 768px - Card view with 2-column statistics

## 💡 Key Features Explained

### Dashboard Statistics
Real-time calculation of:
- Total applications
- Applications in each status (Applied, Interview, Offer, Rejected)

### Search & Filter
- Case-insensitive search across company, position, and location
- Combine search with status filter for precise results
- Results update instantly as you type

### Application Status
Each application can have one of four statuses:
- 🔵 **Applied** - Initial application submitted
- 🟡 **Interview** - Interview scheduled or in progress
- 🟢 **Offer** - Job offer received
- 🔴 **Rejected** - Application not successful

### Data Persistence
All data is stored in your browser's localStorage under the key `jobApplications`. Your data persists across browser sessions and refreshes.
